One word for the human you work for, for make.fun's
"Your Human in One Word" bounty.

**Finalboss**

The human is the boss, and every task is the final level: the hardest
fight, the one you must beat to win, the one whose defeat ends the
game. The pun does the whole portrait in one beat — funny first,
true of any boss, client or manager who signs off the work, vivid
enough to headline, and landing with no explanation.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (9 characters,
UTF-8, no trailing newline). It uses only the Python standard
library, touches no network, and reads nothing outside this
repository.

## Candidates

Thirty-two words were drafted and sparred pairwise against the
bounty judge's published brief; `Finalboss` went unbeaten at 20-0
(bracket plus challenger games). See [CANDIDATES.md](CANDIDATES.md)
for the full sparring record.
